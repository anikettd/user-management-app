📖 About This Project

🎯 Project Summary

The User Management System is a full-stack Angular application that allows you to efficiently manage users.

✨ Features

  • ✅ View all users with active/inactive status
  • ✅ Add new users with form validation
  • ✅ Edit existing user details
  • ✅ Delete users
  • ✅ Dashboard with user statistics

🛠️ Tech Stack

  • ⚡ Angular 22 (Standalone Components)
  • 🎨 CSS3 with responsive design
  • 🔗 RESTful API with JSON Server
  • 📦 RxJS for HTTP calls
